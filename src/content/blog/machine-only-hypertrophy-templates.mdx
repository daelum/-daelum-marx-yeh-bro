Machines aren’t “fake lifting.” They’re tools with fixed paths — great for hypertrophy volume, travel gyms, and days when free-weight skill work isn’t available. Own the **patterns**, not the brand of selectorised stack.

## TL;DR

- Hit squat/hinge, push, pull, carry/core with whatever machines you’ve got.  
- Progress reps then load — [progressive overload](/blog/progressive-overload) · ~**1–3 RIR** — [RPE](/blog/rpe-reps-in-reserve).  
- Useful on travel weeks and joint-sensitive blocks — [hinges](/blog/joint-friendly-hinge-progressions).  
- Still warm up — [warmup](/blog/warmup-before-lifting). Don’t camp stations — [etiquette](/blog/gym-etiquette-without-gatekeeping).

## Template A — full body (3×/week)

| Pattern | Machine examples | Sets × reps |
|---|---|---|
| Squat | Leg press, hack, smith goblet-ish | 3 × 8–12 |
| Hinge | Seated / lying leg curl, back extension, cable pull-through | 3 × 8–12 |
| Push | Chest press, shoulder press machine | 3 × 8–12 |
| Pull | Lat pulldown, cable row, chest-supported machine row | 3 × 8–12 |
| Carry/core | Farmer if DBs exist; else cable anti-rotation / plank | 2–3 |

Maps to [full body](/blog/beginner-full-body-program) logic without a barbell.

## Template B — upper / lower (4×)

**Upper:** chest press, row, shoulder press, pulldown, optional arm machines.  
**Lower:** leg press, hinge/curl machine, lunge machine or step-ups if safe, calves/core.

When volume climbs: [upper/lower advanced volume](/blog/upper-lower-advanced-volume). Strength hybrids still prefer some free-weight skill over time — [powerbuilding](/blog/powerbuilding-hybrid-week).

## Cable vs free weight (quick)

Cables shine for constant tension and shoulder-friendly angles; free weights win for transferable skill. Mix when you can — see also [barbell vs DB bench](/blog/barbell-vs-db-bench-shoulders).
