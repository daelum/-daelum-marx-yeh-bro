**Scope:** Training sequel · after [upper / lower split](/blog/upper-lower-split) · [Start here · training](/start-here#step-2).

You’ve run upper/lower for a while. Sleep and food aren’t a dumpster fire. The logbook still moves some weeks — then stalls. The temptation is “add seventeen extras.” Sometimes you need **more recoverable volume**. Sometimes you need a [deload](/blog/deload-week). This is how to tell.

## TL;DR

- Earn volume: consistent 4× weeks, solid [RIR](/blog/rpe-reps-in-reserve), [logbook](/blog/training-logbook) honesty.
- Add **one set** to a lagging pattern first — not a whole new program.
- Keep most work ~1–3 RIR; daily failure cosplay is not advanced — [ego lifting](/blog/ego-lifting-vs-training-age).
- If life stress spikes, cut volume before you cut sleep — [stress](/blog/stress-and-lifting) · [plateau checklist](/blog/plateau-checklist-for-lifters).

## Prerequisites (be honest)

| Ready-ish | Not ready |
|---|---|
| Hitting most planned sessions | Missing half the week — [how many days](/blog/how-many-days-to-lift) |
| Warmups and bracing sorted — [warmup](/blog/warmup-before-lifting) · [grip/belts](/blog/grip-belts-when-gear-helps) | Joints angry on light sets |
| Protein + sleep roughly in place | Living on four hours + vibes |

Still on full body? Stay there until upper/lower is earned — [full body](/blog/beginner-full-body-program).

## Volume landmarks (practical, not gospel)

Think in **hard sets per pattern per week** (count work sets near target RIR, not warmups):

| Pattern | Intermediate-ish weekly hard sets (rough) |
|---|---|
| Squat pattern | ~6–12 |
| Hinge | ~4–10 — see also [joint-friendly hinges](/blog/joint-friendly-hinge-progressions) |
| Horizontal push | ~6–12 |
| Horizontal pull | ~6–14 |
| Vertical push / pull | ~4–10 each |

These are **ranges**, not a personality. Women and men use the same physics — [progressive overload for women](/blog/progressive-overload-for-women). Smaller jumps beat hero weeks.

## How to add without frying

1. Pick **one** lagging pattern (e.g. horizontal pull).  
2. Add **one** work set on one upper day.  
3. Hold for 2–3 weeks; watch sleep, pumps, and bar speed.  
4. Only then consider another set or a second variation.  
5. Schedule a deload every 4–8 weeks of hard pushing — or sooner if needed.

Accessories shouldn’t out-volume the mains forever. Pump work is seasoning.
