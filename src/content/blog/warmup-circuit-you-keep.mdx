**Scope:** Training habit · expands [warmup before lifting](/blog/warmup-before-lifting) · [Yeh Bro System · training](/start-here#step-2).

Warmups fail two ways: skipped entirely, or turned into mobility theatre. Build a **circuit you’ll actually run** — five to twelve minutes — then ramp into work sets. The point isn’t Instagram flow. It’s available top sets and fewer “cold first rep” surprises.

## TL;DR

- Same three layers: raise → pattern prep → ramp — [warmup guide](/blog/warmup-before-lifting).
- Write one default circuit; tweak by session (upper/lower).
- Bands optional — [resistance bands](/go/bands-amz).
- If you’re injured/returning, lengthen prep — [injury return](/blog/injury-return-to-lift-mindset).

## Default circuit (≈8 minutes)

| Block | Examples | Time |
|---|---|---|
| Raise | Bike, row, brisk walk | 2–3 min |
| Hips / T-spine | World’s greatest stretch, openers | 2 min |
| Pattern | Bodyweight squat or hinge + band pull-aparts | 2 min |
| Ramp | Empty bar → light → moderate toward first work weight | 2–4 min |

**Upper day:** arm circles, face pulls, light push-ups. **Lower day:** ankle rocks, glute bridge, light Romanian deadlift (RDL) — [hinges](/blog/joint-friendly-hinge-progressions). Full-body days: raise once, then ramp the **first big lift** thoroughly — later patterns need less ceremony once you’re warm — [full body program](/blog/beginner-full-body-program).

## Why short circuits stick

A warmup only works if it survives Tuesday after work. Long mobility podcasts die the first week you feel busy. Short circuits survive because:

1. They have a **hard time cap**.
2. They reuse the **same patterns** as the session.
3. They end in **ramp sets** that already feel like training — so you don’t treat prep as optional fluff.

**Opinion (practical):** most lifters need better ramp sets more than they need a new stretch library. For the physiology of raise / prep / ramp, stay with [warmup before lifting](/blog/warmup-before-lifting). This page is the habit wrapper.

## Ramp sets are part of the circuit

People treat the circuit as “mobility,” then jump to working weight and wonder why bar speed feels trash. Example for a planned ~100 kg squat work set:

| Set | Load | Reps |
|---|---|---|
| 1 | Empty bar | 5–8 |
| 2 | ~40–50% | 3–5 |
| 3 | ~70% | 2–3 |
| 4 | ~85% | 1–2 |
| Work | Planned | Planned reps at honest **reps in reserve (RIR)** — [rate of perceived exertion (RPE)](/blog/rpe-reps-in-reserve) |

Heavier top sets → more ramp patience. Light accessories → shorter ramps. Leave the foam-roll podcast for another time.

## Rules so you keep it

1. Cap at ~12 minutes unless rehabbing or coming in cold from a desk day.
2. No phone rabbit holes mid-circuit. Timer on, circuit done, then train.
3. Log “WU done” so skipping is visible — [logbook](/blog/training-logbook).
4. Home gym: same circuit in the garage — [home gym mistakes](/blog/beginner-mistakes-home-gyms).
5. Cardio finishers aren’t warmups — [cardio on lifting days](/blog/cardio-on-lifting-days).
6. Seasonal honesty: colder mornings, older joints, and post-travel sessions get a longer raise, not a harder first set — [travel gym](/blog/hotel-travel-gym-sessions).

Bands are optional openers when cables are busy or you’re in a hotel — [resistance bands](/go/bands-amz). They’re not a second workout.

## Sample upper vs lower (copy/paste)

**Upper (before press/row focus)**

1. 2 min easy bike or row  
2. Band pull-aparts × 15, face pulls × 12  
3. Push-up or empty-bar press × 8  
4. Ramp into first press work set  

**Lower (before squat/hinge focus)**

1. 2–3 min brisk walk or bike  
2. Hip opener + glute bridge × 8  
3. Bodyweight squat or light RDL × 8  
4. Ramp into first squat/hinge work set  

If a joint feels angry, keep the circuit and **lower the first work-set ego** — don’t skip prep to “save time,” then grind a cold heavy set. Returning from time off? Lengthen prep and leave more RIR — [injury return](/blog/injury-return-to-lift-mindset).

## Common mistakes

| Mistake | Fix |
|---|---|
| Foam-roll everything for 20 minutes | Raise + pattern + ramp. Save long rehab for dedicated days. |
| One empty-bar set then max effort | Use 2–4 ramp sets. Feel the groove. |
| Different random warmup every session | One default. Tweak, don’t reinvent. |
| Skipping when late | Cut accessories later — keep the 8-minute circuit. |
| Treating HIIT as a warmup | Hard conditioning ≠ ramp sets — [cardio on lifting days](/blog/cardio-on-lifting-days). |
| Pre-workout as a tissue substitute | Stim ≠ warmup — [caffeine dose](/blog/caffeine-dose-training). |

If every session needs a longer and longer warmup just to feel normal, that’s a recovery signal — [deload styles](/blog/how-to-choose-deload-style) · [sleep](/blog/sleep-for-lifters) — not a cue to buy more bands.

## Soft close

Boring warmup = available top sets. Run the same short circuit, ramp with intent, then progress — [RPE / RIR](/blog/rpe-reps-in-reserve) · [Yeh Bro System](/start-here).
