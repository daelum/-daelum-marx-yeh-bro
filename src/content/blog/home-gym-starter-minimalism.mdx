A home gym fails when it’s a shopping addiction with dust on it. It works when you can hit **squat/hinge, push, pull** most weeks without a commute excuse. Start minimal. Upgrade when a pattern is truly blocked — not when a sale email hits your phone.

## TL;DR

- Buy for **patterns**, not brands: squat/hinge, push, pull, carry/core.
- Phase 1: bands + adjustable dumbbells (DBs) (or a small dumbbell range) + a pull option.
- Phase 2: bench + rack/stand when squats and heavy hinges demand it.
- Soft live hops: [resistance bands](/go/bands-amz) · [VOLTRX electric shaker](/go/shaker-amz) — no invented rack affiliate.
- Consistency beats catalogue completeness — [beginner home-gym mistakes](/blog/beginner-mistakes-home-gyms).

## Minimum viable setup

| Need | Cheap-ish solutions |
|---|---|
| Squat pattern | Goblet / DB squat; later rack + bar |
| Hinge | DB Romanian deadlift (RDL); trap/bar later — [hinge progressions](/blog/joint-friendly-hinge-progressions) |
| Push | Push-ups, DB press, floor press |
| Pull | Bands, backpack rows, doorway options cautiously; later pull-up bar / DB rows |
| Carry / core | Suitcase DB carries, planks |

Programs: [full body](/blog/beginner-full-body-program) maps cleanly to home gear; [upper/lower](/blog/upper-lower-split) when space/time allow. Machine-only commercial gyms are a different constraint set — [machine-only templates](/blog/machine-only-hypertrophy-templates) — but the pattern logic is the same.

## Buy in phases (so you actually train)

**Phase 1 — train this month**

- Adjustable DBs or a short fixed pair range you will use
- A band set for warm-ups and rows
- Floor space you will not trip over
- A way to log sessions — [training logbook](/blog/training-logbook)

**Phase 2 — when Phase 1 is boring because you’re strong**

- Flat bench you trust
- Rack or sturdy stands for heavier squats / overhead work
- A bar and plates *if* you have the footprint and flooring

**Phase 3 — optional flavour**

- Specialty bars, cables, sleds — only after Phase 2 is earning its keep

If Phase 1 gear is still covered in shipping plastic while you browse Phase 3, you do not have a gym problem. You have a shopping problem.

## What to delay

| Skip for now | Why |
|---|---|
| Seventeen specialty bars | Ego collection |
| Full cable jungle | Expensive for beginners |
| “Functional” gimmicks | Patterns already covered |
| Max plates before a rack | Safety first |
| Mirrored influencer aesthetic | Train first; decorate later |

Etiquette with housemates: noise hours, mats, re-rack your own garage — [gym etiquette](/blog/gym-etiquette-without-gatekeeping) still applies at home. A home gym that starts family wars does not get used.

## Progression without a commercial plate tree

Progressive overload still works with DBs and bands:

- Add reps, then load
- Slow the eccentric
- Shorten rest slightly *without* turning every set into cardio
- Move to a harder variation (floor press → bench; band row → chest-supported DB row)

When a lift stalls because the next DB jump is huge, use pause reps, tempo, or an extra set before you declare you “need” a full rack. Details: [progressive overload](/blog/progressive-overload) · [RPE / RIR](/blog/rpe-reps-in-reserve).

## Common mistakes

- Buying the “complete garage” before proving three weeks of sessions
- Skipping pull work because push-ups feel easier to set up
- Ignoring flooring and dropping plates into a downstairs neighbour war
- Collecting bands you never progressive-overload
- Treating home training as optional soft mode — ego load still needs honest positions

## Takeaways

Space to train beats a catalogue. Hit sessions, progress load somehow — DBs, bands, then iron — [progressive overload](/blog/progressive-overload) · [Yeh Bro System](/start-here).
