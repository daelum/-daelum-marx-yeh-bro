A home gym fails when it’s a shopping addiction with dust on it. It works when you can hit **squat/hinge, push, pull** most weeks without a commute excuse. Start minimal. Upgrade when a pattern is truly blocked.

## TL;DR

- Buy for **patterns**, not brands: squat/hinge, push, pull, carry/core.  
- Phase 1: bands + adjustable DBs (or a small dumbbell range) + a pull option.  
- Phase 2: bench + rack/stand when squats and heavy hinges demand it.  
- Soft live hops: [resistance bands](/go/bands-amz) · [VOLTRX electric shaker](/go/shaker-amz) — no invented rack affiliate.

## Minimum viable setup

| Need | Cheap-ish solutions |
|---|---|
| Squat pattern | Goblet / DB squat; later rack + bar |
| Hinge | DB RDL; trap/bar later — [hinge progressions](/blog/joint-friendly-hinge-progressions) |
| Push | Push-ups, DB press, floor press |
| Pull | Bands, backpack rows, doorway options cautiously; later pull-up bar / DB rows |
| Carry / core | Suitcase DB carries, planks |

Programs: [full body](/blog/beginner-full-body-program) maps cleanly to home gear; [upper/lower](/blog/upper-lower-split) when space/time allow.

## What to delay

| Skip for now | Why |
|---|---|
| Seventeen specialty bars | Ego collection |
| Full cable jungle | Expensive for beginners |
| “Functional” gimmicks | Patterns already covered |
| Max plates before a rack | Safety first |

Etiquette with housemates: noise hours, mats, re-rack your own garage — [gym etiquette](/blog/gym-etiquette-without-gatekeeping) still applies at home.
