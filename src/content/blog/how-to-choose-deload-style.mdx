**Scope:** Recovery programming · companion [deload week](/blog/deload-week) · [Start here · training](/start-here#step-2).

A **deload** is a planned easier week so the next block doesn’t fall over. The style you pick depends on whether you’re preventing fatigue or already cooked. This expands the basic deload guide into a decision tree.

## TL;DR

- **Proactive:** schedule easier weeks every 4–8 hard weeks.  
- **Reactive:** cut load now if sleep, mood, or bar speed are trashed.  
- Default for most lifters: keep some intensity, **cut volume ~30–50%**.  
- Deload ≠ week of ego maxes “for CNS” cosplay — [ego lifting](/blog/ego-lifting-vs-training-age).

## Styles compared

| Style | How | Best when |
|---|---|---|
| **Volume cut** | Same lifts, fewer sets | Default lifter fatigue |
| **Intensity cut** | Lighter loads, keep some volume | Joints angry, technique shaky |
| **Exercise swap** | Machine / DB variations | Specific tweak nagging — [hinges](/blog/joint-friendly-hinge-progressions) |
| **Frequency cut** | Drop a session | Life / shift work — [late-shift sleep](/blog/sleep-hygiene-late-shift-lifters) |
| **Active recovery week** | Walks + mobility | Mentally fried — [rest days](/blog/rest-days-vs-active-recovery) · [steps](/blog/step-targets-without-obsessing-neat) |

Details on the classic volume cut: [deload week](/blog/deload-week).

## Decision tree

1. Sharp pain / injury concern → clinician; don’t “deload through” serious injury.  
2. Poor sleep + rising RPE for days → reactive volume cut now — [RPE](/blog/rpe-reps-in-reserve) · [sleep](/blog/sleep-for-lifters).  
3. End of a hard block, feeling OK → proactive volume cut.  
4. Powerbuilding / high volume block → don’t skip scheduling — [powerbuilding](/blog/powerbuilding-hybrid-week) · [advanced volume](/blog/upper-lower-advanced-volume).  
5. Deep cut + fatigue → food and deload together — [cutting](/blog/cutting-without-wrecking-lifts) · [reverse diet](/blog/reverse-diet-literacy) if the cut is ending.

## What to keep

- Practice patterns lightly — skill doesn’t need max load.  
- Creatine habit — [Muscle Nation creatine monohydrate](/go/creatine-amz).  
- Protein — [protein targets](/blog/protein-targets-for-lifters).  
- Log the easy week so you don’t “forget” it happened — [logbook](/blog/training-logbook).
